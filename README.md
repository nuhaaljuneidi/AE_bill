# Energy3D Electricity Cost Calculator

A calculator that turns Energy3D simulation results into an electricity bill, so students can see how building design affects cost. Built for Engineering Day.

## Live tool

[Open Energy3D Electricity Cost Calculator](https://nuhaaljuneidi.github.io/AE_bill/)

## Features

- Electricity rates for every U.S. state, or a custom rate.
- Compare the cost of two design choices, such as roof or thermostat options.
- Unlocks after the student enters their name.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
